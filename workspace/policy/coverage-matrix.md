# Coverage Matrix (DEMO) — quick lookup for PolicyMatcher
| Category | Covered? | Notes |
|---|---|---|
| Accident (lacerations, fractures, FB ingestion) | Yes | 0-day wait |
| Illness (infections, GI, derm, endocrine) | Yes | 14-day wait |
| Orthopedic / cruciate (CCL, luxating patella) | Yes | 6-month wait |
| Diagnostics (bloodwork, imaging, biopsy) | Yes | if tied to covered dx |
| Surgery + anesthesia + hospitalization | Yes | if tied to covered dx |
| Prescription meds | Yes | non-Rx supplements excluded |
| Dental illness (extractions, infection) | Yes | routine cleaning only w/ Wellness add-on |
| Wellness (vaccines, annual exam, heartworm prev) | Only if addons includes "wellness" | |
| Behavioral therapy | Conditional | if vet-prescribed for covered condition |
| Pre-existing | No | hard exclusion |
| Cosmetic/elective | No | hard exclusion |
